# MiyooPod Artist/Album grouping mod

This fork groups albums by Album Artist after removing explicit `feat.`, `feat`, `ft.`, `ft`, and `featuring` suffixes for album grouping only. Track metadata is not modified.

GitHub Actions workflow: `.github/workflows/build-miyoopod-arm.yml`

Run it from GitHub Actions; the resulting `MiyooPod-feature-grouping.zip` is an artifact ready to copy to the Miyoo SD card.
